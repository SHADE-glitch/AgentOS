# Skill Performance

This file measures the practical performance of each skill.

## Standard record

```text
Skill:
Call Count:
Success Rate:
Misfire Count:
User Satisfaction:
Common Issue:
Optimization Suggestion:
```

## Example

```text
Skill: backend-architect
Call Count: 18
Success Rate: 83%
Misfire Count: 3
User Satisfaction: Good
Common Issue: sometimes used for pure SQL or Redis tuning work
Optimization Suggestion: tighten activation rules to prefer database-engineer for cache and SQL task types
```

## Use in optimization

The goal is to identify:

- frequently used skills
- under-used skills
- skills with recurring misfire patterns
- skills whose output contract needs tightening
