# Evolution Effectiveness

## Goal

Prove that the evolution loop makes the system better over time.

## Before/After Format

```markdown
Before:
- Router accuracy: 82%
- Skill failure rate: 15%

After:
- Router accuracy: 88%
- Skill failure rate: 10%

Improvement:
- +6% routing accuracy
- -5% failure rate

Reason:
- added RAG routing rules
- clarified boundary between backend-architect and distributed-system
```

## Rule

Any improvement claim must be backed by before/after benchmark evidence or repeated failure analysis.
