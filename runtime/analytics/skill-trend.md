# Skill Trend Analysis

## Goal

Measure whether skill effectiveness is stable or drifting over time.

## Example

```text
backend-architect
- week 1: 95% success
- week 2: 90%
- week 3: 88%
Trend: slight decline; investigate skill drift
```

## Decision rule

If a skill's success rate falls consistently over multiple periods, trigger a skill investigation and benchmark review.
