# Skill Execution Log

This log records how each skill performs in real execution.

## Record format

```text
Date:
Skill:
Task:
Outcome: Success / Partial / Failure
Quality: Excellent / Good / Needs Improvement
Reason:
User Feedback:
Observed Improvement:
```

## Example

```text
Date: 2026-08-30
Skill: backend-architect
Task: 设计商品服务接口与模块边界
Outcome: Success
Quality: Good
Reason: Architecture was clear and trade-offs were explained.
User Feedback: Need more explanation of cache invalidation boundaries.
Observed Improvement: Add explicit data consistency and cache invalidation decision rules.
```

## Review questions

- Which skills are repeatedly successful?
- Which are misfiring or too generic?
- Which need tighter output contracts?
- Which skills need more support context?
