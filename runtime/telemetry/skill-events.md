# Skill Events

## Event format

```yaml
event_id: S-000
timestamp: 2026-08-30T15:00:00Z
skill: "rag-engineer"
operation: "execution"
usage_count: 1
success: true
failure_count: 0
conflict_count: 0

```

## Purpose

This record tracks skill-level performance, including usage frequency, success rate, and recurring boundary conflicts.
