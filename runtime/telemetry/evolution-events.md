# Evolution Events

## Event format

```yaml
event_id: E-000
timestamp: 2026-08-30T15:00:00Z
event_type: "proposal_generated"
proposal_id: "P-001"
source: "runtime failure review"
status: "pending"
reviewed_by: "human"
benchmark_reference: "tests/router-benchmark.md"
```

## Purpose

This record captures each proposal, review decision, and benchmark verification event in the evolution loop.
