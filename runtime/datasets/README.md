# Real World Task Datasets

This directory stores real execution data for the Agent OS.

The goal is to collect real user tasks, score their outcomes, and establish the first production baseline for routing and skill effectiveness.

## Structure

- `raw/tasks.md`
- `classified/task-category.md`
- `benchmark/real-world-benchmark.md`

## Sampling rule

The system should collect a minimum of 50 real task samples before claiming a stable baseline.
