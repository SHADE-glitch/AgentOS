# Release Log

This file records the relevant system-level evolutions.

## Template

```text
Version:
Date:
Component:
Change:
Reason:
Benchmark Status:
Reviewer:
```

## Example

```text
Version: router-1.1
Date: 2026-08-30
Component: agent-router
Change: added decision pipeline and benchmark-aware confidence checks
Reason: reduce wrong routing in RAG and SQL tasks
Benchmark Status: pending benchmark validation
Reviewer: human
```
