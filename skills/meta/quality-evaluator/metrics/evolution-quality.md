# Evolution Quality Metrics

## Objective

Track whether the evolution loop is creating useful improvements without increasing instability.

## Metrics

```text
Proposals Generated:
Proposals Accepted:
Proposals Rejected:
Improvements Verified:
Regression Count:
Average Review Time:
Current Status:
```

## Example

```text
Proposals Generated: 5
Proposals Accepted: 3
Proposals Rejected: 1
Improvements Verified: 2
Regression Count: 0
Average Review Time: 2 days
Current Status: stable
```
