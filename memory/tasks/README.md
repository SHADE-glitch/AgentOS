# Tasks

This directory stores task execution memories.

Each task memory must capture:
- Task context (id, category, difficulty, domains)
- Execution mode (single/multi)
- Agents involved (lead, support)
- Quality results (4-dimension scores)
- Key observations and decisions

Organized by category: architecture/ backend/ ai/ frontend/ optimization/

The `examples/` subdirectory contains reference/template structures.

See `memory/README.md` for the full memory schema.
