# Project Lifecycle Model

## Phase 1: Project Start
- Use `learning-strategist` to define the plan
- Capture goals, stack, missing knowledge, and roadmap

## Phase 2: Development
- Route to the correct domain specialist
- Record key technical decisions and design constraints

## Phase 3: Problem Solving
- Document errors in `knowledge/mistakes`
- Capture root cause and correct pattern

## Phase 4: Project End
- Use `project-mentor` + `agent-evolution-engineer`
- Generate retrospective and update `memory/project-history.md`
