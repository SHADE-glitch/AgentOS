# Hypothesis

This directory stores proposed rules, patterns, or changes that await validation.

Each hypothesis must answer:
- What is proposed?
- What is the supporting evidence? (if any)
- What is the current confidence level?
- What validation is required?
- What is the current status? (untested | testing | supported | rejected)

**Critical rule**: Hypothesis ≠ Fact. Any "should do X" statement without validation evidence belongs here, not in patterns/ or decisions/.

See `memory/README.md` for the full memory schema.
