# Effectiveness

This directory stores per-skill, per-agent, and per-team-pattern effectiveness tracking.

Each effectiveness record must answer:
- Which skill/agent/pattern?
- How many tasks has it participated in?
- What was the observed quality?
- What task types is it best/worst at?

**Important**: Do not fabricate "success_rate = 92%" from small samples.
Record observations, task_count, and mean_quality. Let the data speak.

See `memory/README.md` for the full memory schema.
